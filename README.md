# Brief Overview

A personal finance tracking application which tracks cash inflow and cash outflow in user's account.User can log his/her daily transactions into the application and then can view analysis on how much money is spent vs their income.User can also create budgets i.e target amount beyond which they won't spend any money while they are doing activity which can lead to huge expenses,such as trip ,eating outside,using private transport facilities.The application allows user to perform following the following functions.
->Add Transaction
->View Transacions
->Delete Transaction
->Create budgets
->Delete budgets
->View Analytics based on period[1 month,6 months,1 year]
